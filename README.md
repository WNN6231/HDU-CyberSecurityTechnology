# HDU-CyberSecurityTechnology

> **杭州电子科技大学（HDU）- 网络安全技术实验汇总**

本项目用于存放 2025 学年《网络空间安全技术》课程的相关实验项目、脚本及实验报告。内容包括陈老师的SQL注入、iptables防火墙设置；吕老师数据分类、密码系统设计实验；王老师SYN泛洪攻击、钓鱼网站实验；高老师高级组实验（内容较多详看实验四目录）

---

## 课程资源与工具
* **开发语言**: Python 3.10+ (核心脚本实现)
* **实验教材**: 《网络安全实验教程》（沈鑫剡、俞海平 编著）
* **常用工具**: Kali Linux, Cisco Packet Tracer

---

### 2025 在 HDU 学习网安技的项目汇总

本仓库记录了 **网络安全技术** 课程的全部上机实践，包含对称/非对称加密实现、防火墙配置以及典型的网络攻击模拟。

* **实验重点**：侧重于对计算机网络中交换机、路由器等经典攻击手法的深度理解、加密算法的逻辑实现以及安全防御策略的部署。
