### 2025 在 HDU 学习网安技的项目汇总

本仓库记录了 **网络安全技术** 课程的全部上机实践，包含协议漏洞分析、对称/非对称加密实现、防火墙配置以及典型的网络攻击模拟。

* **技术栈**：主要使用 **Python** 进行网络报文处理与自动化分析。
* **实验重点**：侧重于对底层协议（TCP/IP）的深度理解、加密算法的逻辑实现以及安全防御策略的部署。
* **个人经验**：网安实验重在“调试”和“环境”。建议大家：
   * 1. **环境先行**：先配置好虚拟网络环境或 Python 依赖库（如 `scapy`, `cryptography`）。
   * 2. **抓包验证**：代码跑不通或者逻辑对不上时，第一时间打开 Wireshark 观察真实流量。
   * 3. **安全新闻**：平时多关注安全社区动态，实验中的很多攻击手段在现实中都有变体。
   * 4. **文档记录**：实验截图要随做随截，否则复现环境的过程非常痛苦！😋

## 实验开发与操作流程
1. **需求分析**：明确实验目标（如：如何截获并篡改一个 HTTP 数据包）。
2. **环境搭建**：配置 Python 虚拟环境，确保相关安全库已正确安装。
3. **脚本编写**：使用 Python/Scapy 编写模拟攻击或防御的逻辑代码。
4. **过程验证**：在虚拟机或实验平台上运行脚本，同步使用 Wireshark 进行流量审计。
5. **撰写报告**：分析实验现象，记录遇到的报错（如 Scapy 权限问题、加密填充错误等）及解决方法。
